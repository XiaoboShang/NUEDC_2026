## 使用提示

- 带 `image` 的部署示例通常需要自行准备测试图片；带 `video` 或 `camera` 的示例通常直接使用摄像头。
- AI 示例通常依赖 `/sdcard` 中对应的 KModel、标签或 JSON 配置，运行前需要检查脚本内路径。
- 硬件示例中的引脚号、屏幕型号、I²C/SPI/UART 编号应按实际开发板接线调整。
- `14-Socket/udp_multicast_receiver_pc.py` 和 `udp_multicast_sender_pc.py` 是电脑端脚本，当前第 5 行裸 `Note:` 会触发语法错误，需要先注释或改成字符串。
