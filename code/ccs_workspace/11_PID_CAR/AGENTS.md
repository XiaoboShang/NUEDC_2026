# 电赛项目工作规则

## 工作范围

- 阅读并整理赛题、数据手册和项目文档。
- 分析、解释和修改项目代码。
- 可以编写 C、C++、Python、MATLAB 和 Verilog 等源码。
- 不执行编译。
- 不执行烧录。
- 不控制串口、仪器或其他硬件。

## 硬件使用

- 天猛星MSPM0g3507开发板
- 庐山派k230板卡

## 修改代码规则

- 修改前先阅读相关文件和调用关系。
- 优先采用小范围修改，不随意重构无关代码。
- 不修改第三方库、生成文件和历史备份，除非明确要求。
- 保留现有接口和代码风格。
- 对不确定的硬件参数、寄存器和引脚定义，先查阅数据手册或询问。
- 不凭空编造 SDK 函数、寄存器地址或器件参数。

## 修改后检查

- 检查函数声明和调用参数是否一致。
- 检查数组越界、空指针、未初始化变量和资源释放。
- 检查整数溢出、定点数精度以及有符号/无符号转换。
- 检查物理量单位、采样率、时间常数和坐标系。
- 检查中断与主循环之间的共享变量。
- 检查状态机是否存在不可达状态或无法退出的状态。
- 说明修改了哪些文件、为什么修改，以及仍需人工验证的内容。

## 赛题分析规则

- 首先提取基础要求、发挥要求、限制条件和评分指标。
- 明确区分题目原文、合理推断和待确认事项。
- 给出方案时说明优点、缺点、风险和所需模块。
- 引用关键器件参数时优先使用官方数据手册。
